# Self-Hosted Music Pipeline

Cansado de depender de plataformas de streaming? Eu também. Por isso, montei esse projeto: uma alternativa 100% self-hosted rodando no meu servidor Debian.

Ele estuda o que eu escuto, cria playlists de descobertas da semana, baixa as músicas com as capas originais, e joga tudo para um servidor particular onde posso ouvir do PC ou do celular.
